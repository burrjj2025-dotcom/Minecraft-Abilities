# Minecraft-Abilities
Gives players abilities in the form of /effect. But in a safe, controlled way. Use this plugin instead of giving everyone op on a cheat server. I also lost the source code of this project due to an OS reinstall.


Minecraft-Abilities-1.0-mc1.20-stable.jar is the unmodified first version of this mod that I have made. Its API version in plugin.yml is 1.20. But it should run on other versions like 1.17 if you change the API version in its plugin.yml.

Minecraft-Abilities-1.0.mc1.17-stable.jar is a modified version of Minecraft-Abilities-1.0.mc1.20-stable.jar (after compilation). I opened the internal plugin.yml and changed the API version to 1.17. The plugin was likely compiled for 1.20, as I found the API version line set to 1.20, but it may have also been compiled with multi-Minecraft version support with the intention of the user(like me or you) changing the API version in plugin.yml before or after compilation (both seem to work fine). It runs as expected and has been tested on 1.17. It also has been tested on 1.21.11 and can likely run on MC versions as low as 1.13+ if you change the API version in plugin.yml. I am not up to testing that right now, but anyone else can

Both of these files are the same as far as bytoecode is concerned. The only small difference is that in one of them, I changed the API version line in the internal plugin.yml to 1.17
